# Images Directory

This folder contains all images for the D'Angelo's Pizzeria website.

## Required Images

### Logo & Branding
- **logo.png** - Restaurant logo (recommended: 500x500px, transparent background)
- **og-image.webp** - Social media preview image (1200x630px)

### Hero Section
- **hero-bg.jpg** - Hero background image (1920x1080px minimum)
  - Should feature: Pizza, restaurant interior, or food photography
  - Dark overlay will be applied for text readability

### About Section
- **about-pizza.jpg** - About section image (800x600px)
  - Should feature: Pizza making, chef, or restaurant ambiance

### App Section
- **app-mockup.webp** - Mobile app mockup (800x1200px)
  - Should feature: Phone displaying the app interface
- **appstore.webp** - App Store download button (provided)
- **playstore.webp** - Google Play download button (provided)

## Image Guidelines

### Format
- Use **WebP** format for photos (better compression)
- Use **PNG** for logos and graphics with transparency
- Use **JPG** for photos without transparency

### Optimization
- Compress all images before upload
- Recommended tools: TinyPNG, Squoosh, ImageOptim
- Target file sizes:
  - Hero images: < 500KB
  - Section images: < 300KB
  - Logos: < 100KB

### Dimensions
- Hero backgrounds: 1920x1080px (16:9 ratio)
- Section images: 800x600px (4:3 ratio)
- Logo: 500x500px (1:1 ratio)
- OG image: 1200x630px (1.91:1 ratio)
